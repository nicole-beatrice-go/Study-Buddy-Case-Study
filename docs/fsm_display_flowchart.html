Study Buddy — Display FSM

What the Mini Pupper LCD shows during a study session. The number (whole minutes remaining) is redrawn only when the minute changes (~once/min) to keep the slow framebuffer push cheap; faces are picked by refresh_mood(), with presence faces (worried/sleepy) taking priority.

decision / state show NUMBER show FACE

1. Per-tick decision: NUMBER vs FACE

flowchart TD
  A["step - each tick"] --> B{"state == STUDYING
AND phase == study
AND not paused
AND now >= face_until"}
  B -- yes --> C["SHOW NUMBER
minutes = ceil of time_left / 60"]
  C --> D{"minute changed?"}
  D -- yes --> E["publish Int32 minutes
to expression node"]
  D -- no --> F["do nothing"]
  B -- no --> G["SHOW FACE
refresh_mood picks one"]
  G --> H{"which face?"}
  H -- paused --> I["SAD"]
  H -- break phase --> J["HAPPY"]
  H -- start 1s flash --> K["NEUTRAL"]
  H -- user left --> L["WORRIED"]
  H -- asleep --> M["SLEEPY"]

  classDef num fill:#d6f5d6,stroke:#34a853;
  classDef face fill:#ffe9c7,stroke:#e8902a;
  classDef dec fill:#dbe9ff,stroke:#4374e0;
  class C,E num;
  class G,I,J,K,L,M face;
  class B,D,H dec;

2. Session lifecycle: face / number over time

flowchart TD
  S["tap + present"] --> N1["NEUTRAL face
~1 s flash"]
  N1 --> NUM["NUMBER 24 ... 1
update each minute"]
  NUM -- voice pause --> SAD["SAD face
held until resume"]
  SAD -- voice resume --> NUM
  NUM -- study timer hits 0 --> HAPPY["HAPPY face
break phase"]
  HAPPY -- break over --> START["START
happy, wait for tap"]
  START --> S

  classDef num fill:#d6f5d6,stroke:#34a853;
  classDef face fill:#ffe9c7,stroke:#e8902a;
  class NUM num;
  class N1,SAD,HAPPY,START face;

flowchart TD
  NUM["STUDYING
